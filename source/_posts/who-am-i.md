# 虚构

我是一个可以在自己的心里演话剧的人。即使没人找我聊天，只是让我坐在街边的长椅上，我也会在我的心里，绘声绘色地编撰我自己的故事。

我想，仅仅说是故事的话，有点不太全面，这更像是我自己内心里的小小世界。

在这个小小的世界里，我无所不能！我可以是任何东西，想要活动活动筋骨，我就是一只到处乱哈气的小猫！想要慵懒地晒晒太阳，我就是一棵树，就只是站在那儿进行光合作用，除此之外什么也不做。

我想这也是我进行「虚构」的意义，现实生活实在是太无聊了，不是吗？

而你，我的朋友，你又有多久没有活出自己过了？

# 为什么写博客

说真的，其实我也不是很清楚来着，但是既然注册了 GitHub ，不用 GitHub Pages 搓个 hexo 博客，就感觉少了些什么。

其实可能是更想要让自己多有一些产出？虽然不一定有人看，但是这样稍微记录一下也没什么，对吧？反正也只是记录一些我的一些有的没得想法而已。

至于这些想法……谁知道呢，我说不定第二天，或者一转脸就不认同我自己之前的话了呢，我是这样的人，唉嘿。

虽然也有更深层次一些的原因，我感觉最重要的一点就是，AI 时代了，大家变得更加浮躁了。

这种浮躁体现在，先前网上抬杠，至少是需要输出一下自己的观点的，而现在，「豆包，帮我反驳xxx……」，然后对面一个长篇大论的甚至还带 markdown 标记的文段直接甩评论区里边。

嗯，就感觉，现在网上非常浮躁，至少比先前我认识的互联网更加浮躁了。
